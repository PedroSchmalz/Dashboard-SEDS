# Dados fictícios

Esta pasta contém dados agregados e inteiramente fictícios para demonstração do dashboard. A estrutura dos indicadores foi inspirada nos notebooks analíticos do projeto, mas os valores não foram copiados das bases reais.

- `funil.csv`: volumes municipais das etapas da busca ativa.
- `tempos.csv`: quartis de duração entre etapas.
- `recusas.csv`: motivos declarados de recusa.
- `qualidade.csv`: indicadores agregados de qualidade cadastral.
- `desinteresse.csv`: volume, proporção, qualidade da observação e motivo predominante.
- `atividades.csv`: status das atividades dos PDFs por município.
- `politicas.csv`: inclusões, referência concluída, acesso efetivado e atrasos por política.
- `coortes.csv`: inclusões, acesso, atraso e maturidade mensal.
- `beneficios.csv`: cobertura, pagamentos, valores e defasagem por benefício.
- `pagamentos_municipios.csv`: cobertura municipal fictícia dos benefícios.
- `relatorio_completo.csv`: agregados das colunas do relatório completo por município.
- `dimensoes_completo.csv`: indicadores fictícios por módulo e política pública.
- `municipios_mock.geojson`: limites dos sete municípios citados nos notebooks, obtidos da API de Malhas do IBGE.
- `estado_sp.geojson`: contorno do Estado de São Paulo, obtido da API de Malhas do IBGE.
- `municipios_sp_contexto.geojson`: limites dos 645 municípios usados apenas como contexto cartográfico em cinza.

Competência simulada: junho de 2026. Nenhuma linha representa famílias, agentes, pagamentos ou resultados reais.
